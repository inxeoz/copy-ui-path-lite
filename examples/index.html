Toolbox UI — styles and variations

Self-contained HTML mockups of the floating toolbox. Open any file directly in a browser; no build step required.

Layout variations

  • toolbox-layouts.htmlV1 / V2 / V3
    Re-skin of the dialog as a horizontal floating toolbox: full reference bar, bar plus expandable queue drawer, and an ultra-compact pill. Includes an icon-to-id mapping table.

Visual styles

  • toolbox-styles.htmlS1 / S2 / S3
    Consistent toolbar system with the same control sizes and radii, applied to Paper Frost, Mono Outline, and a three-row Grid stack. Interactive master bar with hover tips, queue pop-up, and settings tab.
  • s3-grid-stack-fixed.htmlS3 fixed
    Style S3 grid stack with a fixed 280×196px toolblock: width and height no longer grow with content.
  • s3-grid-stack-minimal.htmlS3 minimal
    Fixed 280×96px block with the smallest tool set: format select, Copy path, quit.
  • toolbox-pure.htmlpure
    Clean standalone HTML, light sky-blue toolbox, only required icons (child, parent, settings, move, copy path, quit). No path or type preview.

Source of truth

  • a3-design-reference.html
    Static mock of the original carbon-themed sidebar dialog.
  • themes/carbon.json · midnight · paper · mono-outline
    Color tokens. New themes are added here, then rendered with make ui THEME=<name>.
  • templates/picker_ui.j2
    Backend binds to the UI by element id and class hooks, so any of these variations can be recreated by editing the template only.

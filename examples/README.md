# Toolbox UI examples

Self-contained HTML mockups of the floating toolbox UI. Open `index.html`
in a browser; no build step required.

- `toolbox-layouts.html` — layout variations (V1 reference bar, V2 drawer, V3 pill).
- `toolbox-styles.html` — visual styles (Paper Frost, Mono Outline, Grid stack) with interactive master bar.

These examples map every visible control to an existing element id from
`templates/picker_ui.j2`, so the layouts can be reproduced without changing
`src/picker.core.js`.
